## Task 1. Кинематическая модель

**Вход:** параметры из задания, `models/ar601m_arm.yaml`.

**Выбор описания.** Оси суставов заданы как оси x/y/z локальных СО, поэтому вместо DH используется
произведение элементарных преобразований (как в URDF): каждый элемент цепочки — сдвиг вдоль оси
или поворот вокруг оси локальной СО. Это прямо повторяет описание из задания и не требует
подгонки осей под правила DH.

**Цепочка от базы к инструменту** (β = 10°·b):

$$
T(q) = T_z(l_1)\,R_z(q_1)\,R_z(\beta)\,T_y(-b\,l_2)\,R_y(q_2)\,R_x(q_3)\,T_z(-l_3)\,
R_z(q_4)\,R_y(q_5)\,R_x(q_6)\,T_x(l_4)
$$

| Элемент | Смысл | Значение |
|---|---|---|
| l1 | база → плечо, +z | 0.40 м |
| q1 | сустав, ось z | [−90°, 90°] |
| r1 | фиксированный поворот вокруг z | +10°·b |
| l2 | смещение плеча, −b·y | 0.18 м |
| q2 | сустав, ось y | [−105°, 105°] |
| q3 | сустав, ось x | [−45°, 45°] |
| l3 | плечо → центр запястья, −z | 0.30 м |
| q4, q5, q6 | запястье, оси z, y, x | [−90°, 90°] |
| l4 | центр запястья → инструмент, +x | 0.12 м |

**Допущения.** Порядок элементов восстановлен по тексту задания и рисунку 2: l1 до первого
сустава, поворот 10° сразу после q1, сдвиг l2 после него (в локальной СО после поворота),
l3 между плечом и запястьем, l4 в конце. Оси q4–q6 пересекаются в одной точке
(сферическое запястье). Левая рука — зеркальное отражение правой в плоскости x-z,
поэтому знаки l2 и β меняются вместе с b.

**Файл модели.** `models/ar601m_arm.yaml` содержит `arm_side`, `links` (длина, ось, знак),
`fixed_rotations`, `joints` (ось, пределы) и `kinematic_chain` — порядок элементов.
`FK` проходит по `kinematic_chain` и не содержит численных констант робота.

**Проверка** (`run_all.py: task1`, `tests/test_kinematics.py::test_model_loads_six_joints`):
загружено 6 вращательных суставов q1…q6, оси z, y, x, z, y, x, пределы совпадают с заданием — **PASS**.

**Не сделано:** рисунок систем координат.

## Task 3. Аналитическая обратная кинематика

**Метод:** кинематическая развязка (Пипер). Оси q4–q6 пересекаются в центре запястья,
поэтому его положение зависит только от q1–q3.

1. **Центр запястья:** p_w = p − l4·R[:, 0].
2. **Плечо.** Пусть d = p_w − [0, 0, l1]. Из цепочки d = R_z(q1 + β)·v,
   v = [−l3 s2 c3, −b l2 + l3 s3, −l3 c2 c3]ᵀ.
   - |d|² = |v|² = l2² + l3² − 2b l2 l3 s3 ⇒ s3 = (l2² + l3² − |d|²)/(2b l2 l3), q3 ∈ {asin s3, π − asin s3};
   - d_z = −l3 c2 c3 ⇒ q2 = ±acos(−d_z/(l3 c3));
   - q1 = atan2(d_y, d_x) − atan2(v_y, v_x) − β.
3. **Запястье:** R36 = R03ᵀ R = R_z(q4) R_y(q5) R_x(q6) — разложение ZYX;
   вторая ветвь (q4 + π, π − q5, q6 + π).

Итого до 2 × 2 × 2 = 8 ветвей. Все углы приводятся к [−π, π).

**Особые случаи:**
- недостижимо: |s3| > 1 или |c2| > 1 ⇒ ветвь (или вся цель) отбрасывается, возвращается `[]`;
- cos q3 = 0 или v_x = v_y = 0 — q2 или q1 не определяются (вне пределов q3, на практике не встречается);
- q5 = ±90° (gimbal lock): определена только q4 ∓ q6, решений бесконечно много; возвращается
  представитель с q6 = 0 (соглашение scipy).

**Правило дубликатов:** две ветви совпадают, если все |Δq_i| < 1e-9 рад (с учётом −π ≡ π).

**Результаты** (невязка FK по всем ветвям ≤ 1.6e-15 м / рад):

| Рука | Цель | Ветвей до фильтрации | Допустимых | Допустимые ветви, град |
|---|---|---|---|---|
| b = +1 | zero | 4 | 1 | [0, 0, 0, 0, 0, 0] |
| b = +1 | limit | 4 | 1 | [−90, 0, 0, 0, 0, 0] |
| b = +1 | generic | 8 | 1 | [20, −30, 15, 40, −25, 60] |
| b = +1 | недостижимая p = [2, 0, 0] | 0 | 0 | — |
| b = +1 | вырожденная (q5 = 90) | 8 | 1 | [20, −30, 15, −20, 90, 0] |
| b = −1 | zero | 4 | 1 | [0, 0, 0, 0, 0, 0] |
| b = −1 | limit | 4 | 1 | [−90, 0, 0, 0, 0, 0] |
| b = −1 | generic | 8 | 1 | [20, −30, 15, 40, −25, 60] |
| b = −1 | недостижимая p = [2, 0, 0] | 0 | 0 | — |

Для zero и limit ветвей 4, а не 8: c2 = ±1 даёт двойной корень q2 = ±0, дубликаты удалены.

## Task 5. Дифференциальная кинематика

**Соглашение:** [v; ω] = J(q) q̇, v — линейная скорость кончика инструмента, ω — угловая скорость
инструмента, обе в базовой СО.

**Вывод 1 — геометрический.** Для сустава i: o_i — начало его СО, z_i — его ось в базе
(из FK до сустава). Вращение с единичной скоростью даёт
J_i = [z_i × (p − o_i); z_i].

**Вывод 2 — дифференцирование цепочки.** T = A_i R_i(q_i) B_i, где A_i — всё до сустава,
B_i — всё после. dR_i/dq_i = R_i [a_i]×, a_i — локальная ось. Тогда
∂T/∂q_i = A_i R_i S_i B_i, S_i = [[a_i]×, 0; 0, 0], и
J_i = [∂p/∂q_i; vee(∂R/∂q_i Rᵀ)].

**Конечные разности:** центральные, h = 1e-6 рад:
v_i = (p(q + h e_i) − p(q − h e_i))/2h, ω_i = rotvec(R(q + h e_i) R(q − h e_i)ᵀ)/2h.

**Попарные невязки** (норма Фробениуса):

| Рука | Конфигурация | ‖J_geo − J_der‖ | ‖J_geo − J_fd‖ | ‖J_der − J_fd‖ | σ_min(J) |
|---|---|---|---|---|---|
| +1 | generic | 1.0e-15 | 1.2e-10 | 1.2e-10 | 6.20e-2 |
| +1 | около сингулярности, q5 = 89.9° | 9.2e-16 | 1.3e-10 | 1.3e-10 | 2.13e-4 |
| −1 | generic | 7.6e-16 | 1.4e-10 | 1.4e-10 | 4.40e-2 |
| −1 | около сингулярности, q5 = 89.9° | 9.7e-16 | 1.4e-10 | 1.4e-10 | 2.13e-4 |

Два аналитических вывода совпадают до машинной точности; отличие от конечных разностей ~1e-10 —
погрешность самой разностной схемы при h = 1e-6. Около q5 = 90° оси q4 и q6 почти совпадают,
σ_min падает в ~300 раз, но совпадение трёх якобианов сохраняется.

Код: `arm/jacobian.py` (`DifferentialKinematics` = геометрический якобиан). Тест: `test_jacobians_agree`.
